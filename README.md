# 🧪 QA Copilot

An AI-powered QA Assistant built with Python, Streamlit, and Groq AI.

## Features

- 📝 **Test Case Generator** — Paste a user story and get professional test cases instantly
- 🐛 **Bug Report Improver** — Transform rough bug notes into professional reports
- 💬 **QA Mentor Chat** — Ask any QA question and get expert answers
- 📊 **Test Summary Generator** — Convert raw test results into stakeholder-ready reports

## Tech Stack

- Python
- Streamlit
- Groq AI API (llama-3.3-70b-versatile)
- python-dotenv

## How to Run

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Add your Groq API key to `.env` file: `GROQ_API_KEY=your_key`
4. Run: `streamlit run app.py`
